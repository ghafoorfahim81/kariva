# چک‌لیست راه‌اندازی — تست بسته با ~۲۰ متخصص در یک شهر

## پیش از شروع
- [ ] `kariva:preflight --production` بدون خطا
- [ ] OTP واقعی کار می‌کند (روی ۳ شماره آزمایش شد)
- [ ] HTTPS و دامنه، UptimeRobot روی `/api/v1/health`
- [ ] بکاپ شبانه اجرا شده و **بازیابی آزمایش شده**
- [ ] clamav فعال؛ worker زنده
- [ ] حساب ادمین ساخته شد
- [ ] دسته‌ها و ولایت/شهر (seed) درست‌اند

## هفتهٔ تست
- [ ] ۲۰ متخصص با کمک حضوری ثبت‌نام می‌کنند (پروفایل، عکس، خدمت، تأیید هویت)
- [ ] ادمین صف تأیید را همان روز پاسخ می‌دهد
- [ ] هر متخصص حداقل یک درخواست واقعی دریافت می‌کند (مشتریان آشنا)
- [ ] گزارش‌ها و لاگ خطا هر روز بررسی می‌شود

## معیار موفقیت
- ≥ ۱۵ از ۲۰ نفر پروفایل کامل با خدمت دارند
- ≥ ۱۰ سفارش واقعی ثبت و ≥ ۵ تکمیل شد
- هیچ خطای ۵۰۰ تکراری، هیچ نشت سند
- متخصصان بدون کمک می‌توانند پاسخ سفارش بدهند

## تصمیم go / no-go
اگر معیارها برآورده شد → فاز ۴ (عرضهٔ عمومی شهر به شهر). اگر نه: فهرست مشکلات، رفع، تکرار یک هفتهٔ دیگر.
