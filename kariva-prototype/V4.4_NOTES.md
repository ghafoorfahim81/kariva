# Kariva V4.4 — Notification Center

- Responsive notification center from desktop sidebar and mobile/desktop header bell.
- Unread badge, all/unread filters, mark one/all read, navigation to related sections.
- Sample notifications for messages, orders, opportunities, reviews, verification.
- LocalStorage persistence for read state; this is a frontend demo, not real-time notifications.
- No real notifications or identity verification are issued.
