# Kariva V3 — Interactive Product Prototype

Vue 3 + TypeScript + Vite + Tailwind CSS. Built as an extension of the V2 premium prototype.

## Features
- Premium responsive feed, professional discovery, and job opportunities
- Personal profile editor
- Create multiple company/business pages under one personal account
- Switch publishing identity between personal account and business pages
- Create portfolio entries and job opportunities (demo data)
- Profile detail previews, follow, like, save, and post composer
- Dari, Pashto, English UI baseline; light and dark mode

## Run
```bash
npm install
npm run dev
```

## Important
This is a front-end interactive demo. All changes are in browser memory and disappear on reload. No database, account authentication, real media uploads, phone calls, page-manager invitations, or server deployment. Some new V3 form labels are Dari-only placeholders; full translation coverage remains to be implemented. Production architecture target: Laravel + Vue 3 + Inertia.js + PostgreSQL.

Build validation could not be completed in this environment because package installation did not finish. Run `npm run build` after installing dependencies.
