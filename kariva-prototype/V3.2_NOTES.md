# Kariva V3.2 — Ratings & Reviews (interactive demo)
- Star ratings (1–5), text reviews, demo professional replies and report action.
- Verified and unverified reviews are clearly distinguished. New reviews are always unverified.
- Personal profiles and business pages have separate review targets.
- Demo limitations: no backend, identity proof, transaction verification, persistent storage, moderation queue or server-side anti-abuse. Reviews reset on reload.
- Demo replies are available only in the local managed-business context; permissions are NOT secured.
- Run: npm install && npm run dev
