# Kariva V4.5 — Admin Dashboard (Frontend Demo)

- Admin entry in the existing navigation.
- Overview statistics and quick actions.
- Searchable sample personal and company accounts with active/suspended toggles.
- Sample verification review queue, approve/reject actions.
- Sample content moderation and user reports workflows.
- Responsive cards, dark-mode styles, and explicit demo-only labels.

IMPORTANT: This is NOT a secure admin panel. No real authentication, role-based authorization, persistence, document verification, or backend integration exists. Demo state resets on refresh. Never use this frontend to administer real users.
